# Keyboard

This page lists the Tab order and the keys of Installer Analysis.

## What it does

Every control can be reached with the keyboard. A focus frame shows the control that has the focus.

## When to use it

Use it to work without a mouse.

## Requirements

None.

## Steps

### Tab order

Select the **Overview** button in the sidebar, then press Tab. The focus goes through the other sidebar buttons, then to the path box and **Browse...**, then to the action buttons **Copy Summary**, **Copy JSON**, **Export CSV** and **Export HTML**, and then to the content of the view.

### Keys

| Key | Effect |
|---|---|
| Tab, Shift+Tab | Move the focus. |
| Enter, Space | Press the focused button. |
| Enter in the path box | Analyze the file that the path names. |
| Shift+F10 | Open the context menu of the focused control. |
| Esc | Close a dialog or a menu. |

## Limits

- The Tab order follows the layout of the view.

## Troubleshooting

| Message or symptom | Cause | Fix |
|---|---|---|
| A sidebar button is skipped. | The view has no data for this file. | Open another file. |
